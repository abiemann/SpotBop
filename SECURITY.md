# Security Policy

This repository contains a portfolio-oriented Kotlin sample rather than the
installable SpotBop Android application. Security fixes are applied to the
current `main` branch.

Please do not publish suspected vulnerabilities in an issue or pull request.
Use GitHub private vulnerability reporting:

<https://github.com/abiemann/SpotBop/security/advisories/new>

Include reproduction steps and observed impact, but do not send credentials,
signing material, personal information, or other secrets.
